# Decision Review Protocol

1. Load latest Decision State.
2. Read evidence added since last review.
3. Identify changed assumptions.
4. Flag stale high-impact evidence.
5. Update beliefs only where material.
6. Check kill criteria.
7. Check scale criteria.
8. Re-evaluate opportunity cost.
9. Choose: continue / guardrail / test / pivot / pause / kill / scale.
10. Append review record.

Never edit old journal entries to match the new view.

Always distinguish:
- **decision process quality**: was the decision reasonable with information available then?
- **outcome quality**: did the world produce a good/bad result?

A 70% decision can fail. A 10% gamble can win.
