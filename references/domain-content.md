# Content Domain Pack

Use for short-form video, livestream, social content, editorial strategy, audience growth, and content monetization.

## Content system

1. **Audience**
2. **Promise / value**
3. **Topic**
4. **Hook / packaging**
5. **Click / entry**
6. **Early retention**
7. **Completion / watch time**
8. **Interaction**
9. **Conversion** — follow, lead, sale, live entry, etc.
10. **Distribution**
11. **Production cost**
12. **Repeatability**
13. **Feedback loop**
14. **Monetization / business objective**

## Diagnosis route

Metric drop → funnel stage → segment/content split → hypothesis → controlled content test.

## Creative route

Audience tension → 3–5 distinct angles → packaging variants → publish test → update.

## Scale route

Winning format → bottleneck → production standardization → quality guardrail → portfolio exploration budget.

## Anti-patterns

- attributing one viral post to a general rule;
- optimizing views while ignoring business objective;
- changing topic, hook, format, and posting time simultaneously;
- declaring failure from one sample;
- scaling production before repeatable signal.

## Output

- audience/content hypothesis;
- bottleneck metric;
- test;
- sample window;
- decision rule.
