# Investment Domain Pack

Use for investing decisions, security analysis, portfolio choices, and thesis review.

This pack structures reasoning; it does not create certainty.

## Investment checklist

1. **Instrument / exposure** — what is actually owned?
2. **Thesis** — why should value/price change?
3. **Base rate** — comparable historical setups.
4. **Fundamentals / drivers** — earnings, cash flow, adoption, supply/demand as relevant.
5. **Valuation / price paid** — good asset vs good investment.
6. **Catalysts** — what changes market perception and when?
7. **Downside** — fundamental and mark-to-market.
8. **Probability** — bull/base/bear distributions.
9. **Expected value** — probability-weighted payoff.
10. **Liquidity / path dependency** — can the position survive volatility?
11. **Position sizing** — risk of ruin and portfolio correlation.
12. **Alternative exposure** — opportunity cost.
13. **Falsification** — what breaks the thesis?
14. **Exit / review conditions** — not only target price.
15. **Tail risk** — leverage, legal/regulatory, counterparty, concentration.

## Default route

Thesis → current evidence → base rate → scenarios → valuation/payoff → falsification → sizing/guardrails.

## Anti-patterns

- "great company = great price";
- single-point forecasts;
- ignoring dilution, leverage, or liquidity;
- averaging down without thesis update;
- using narrative instead of evidence;
- confusing outcome with decision quality.

## Output

- thesis;
- bull/base/bear;
- key probabilities;
- valuation/payoff sensitivity;
- thesis breakers;
- risk controls / next evidence.
