# Product Domain Pack

Use for product strategy, feature prioritization, MVPs, funnels, onboarding, retention, and product decisions.

## Product map

1. **User / segment**
2. **Job / pain**
3. **Current workaround**
4. **Desired outcome**
5. **Activation moment**
6. **Core behavior**
7. **Retention mechanism**
8. **Value metric**
9. **Friction**
10. **Distribution**
11. **Technical/operational constraints**
12. **Business alignment**

## New product route

User/job → problem evidence → desired outcome → smallest value delivery → MVA → retention signal.

## Feature route

Problem → affected segment → expected behavior change → opportunity cost → reversible experiment → success metric.

## Optimization route

Funnel decomposition → bottleneck → hypothesis → experiment → causal read.

## Anti-patterns

- feature-first thinking;
- shipping an MVP that does not test the key uncertainty;
- optimizing sign-up while retention is broken;
- using average user metrics when segments differ;
- metric movement without causal explanation.

## Output

- user problem;
- product hypothesis;
- priority;
- experiment;
- success/failure threshold;
- follow-up decision.
