# Output Protocols

The reasoning framework should be mostly invisible. Output the result, not a parade of model names.

## FACT / UNDERSTAND

- Answer
- Short explanation
- Caveat/source only if needed

## DIAGNOSE

- Most likely cause(s)
- Why
- Best discriminating test
- Fix
- Verification

## DECIDE

- Recommendation
- Why it wins
- Main alternative and when it would win
- Key uncertainty / strongest risk
- Next action or validation

## PLAN

- Outcome / acceptance criteria
- Modules
- Dependencies / critical path
- Bottleneck
- Milestones
- First action

## EVALUATE

- Verdict: keep / modify / reject
- Strongest parts
- Weakest assumptions
- Top failure modes
- Required changes
- Go/no-go test

## STRATEGY

- Reality / constraints
- Strategic choice
- Trade-offs
- Why now
- Failure conditions
- Resource allocation
- Next experiment / milestone

## FORECAST

- Base case
- Bull case
- Bear case
- Probabilities/ranges where useful
- Leading indicators that would change the forecast

## Output compression rule

If a section does not change understanding, decision, or action, delete it.
